## 已定位的处理路径

额外留白来自部分 `Label` 保留了自动换行时扩大的自身高度。父面板gap始终4像素；UI缩放始终1，autoFit和i18nActive均false，排除了本轮运行中的缩放、翻译适配和gap变化。

实际Runtime使用 urhox-libs 1.0.29，manifest `e0c42c86`；Label资源uuid `H03e0dx-eul7AUwqKsiFGqNb`，hash `41b9f736`。只读检查了本轮Runtime缓存中的真实源文件，并与本地参考库对应章节比对，没有修改任何库。

`Label:Render` 第789–804行附近：自动宽度Label在当前布局宽度小于重新测得的文字宽度时，临时使用自动换行。第992–1014行附近：自动换行分支把测得的文本高度写入 `Widget.SetHeight`。后续恢复单行时，单行分支没有对应的高度回填；于是多行测量产生的高度继续保留。`Phase1.Restart` 经 `UI.Shutdown` → `UI.Init` → 新建Label，构造器按默认单行高度重新初始化，因此重开后额外留白消失。

文字宽度重测与Yoga布局更新之间的过渡触发了这条路径。字体下载/重载可能是宽度重测的触发因素；本轮未单独记录字体ReloadFinished时刻，不能把“异步字体下载”认定为唯一上游触发源。
