# Phase 4～7 统一开发与验收计划

2026-10-14（Asia/Shanghai）。用户已授权连续完成 Phase 7，全部完成后一次验收，覆盖此前逐阶段等待验收的安排。Phase 8 暂不实施。

| 顺序 | 工作 | 交付与验证 |
| --- | --- | --- |
| 1 | Phase 4 自动工作站 | 三槽独立三秒煎肉、误放生肉取回、两秒组合、成品缓存；真实 Runtime 边界和场景生产链检查 |
| 2 | 建筑世界昵称 | 场景 Text3D 子节点，锚点相对建筑固定；靠近显示；不改变场景相机比例，不再用屏幕投影 UILabel |
| 3 | Phase 5 建筑系统 | B 选型、键鼠选型与管理、投影、网格吸附、90°旋转、五格操作距离、合法占地、连续建造、移动取消、删除保留内容 |
| 4 | Phase 6 订单 | 随机 5～15 秒、最多五单、满单暂停、释放后重新等待、HUD 编号/需求/进度；当前 Day 1 固定一份需求，后续 Day 2/3 接口待 Phase 8 调用 |
| 5 | Phase 7 收银 | 交付区五个汉堡、空手取回、主动选单、键鼠交付、部分交付、多余成品保留、完成移除与选择清理 |
| 6 | 统一自检与交付 | 模块边界、完整自动生产→建造→订单→交付链路、自检关闭的正常预览、开发与积分记录、人工验收清单 |

昵称改为世界坐标固定偏移后，字与建筑一起随镜头缩放，屏幕像素间距可随缩放变化；保留建筑上边缘外侧的固定世界锚点，以最新用户“以建筑为坐标点相对固定”要求为准。

不实现 Phase 8 的五分钟日计时、暂停菜单、跨日结算、三天循环和重新开始页面；不调用积分生成能力、不远端构建或提交。普通建筑初始包含 Phase 4 的两台演示设备，进入 Phase 5 后均支持正常移动/删除，也可免费无限建造。
