# V0.3 UI 人工验收清单

适用版本：Demo V0.3；范围 R01～R14 白模 UI。验收目标：Windows 键鼠与小米14 / Android15 横屏触控。正式美术、进度存档及新增玩法不在本轮范围。

这份表供玩家实际操作填写，不能把开发端自动断言结果填成人工通过。每项结果填写 `通过 / 不通过 / 未测 / 待复验`；发现问题记录编号、步骤、实际表现与截图。手机项目必须在真实手机上执行，桌面鼠标与合成触点检查不能替代真机。

验收人：____　日期：____　Windows分辨率/缩放：____　手机版本/安装来源：____

手机前置条件：获取包含本次代码的 Android 测试版本。本轮只做 Windows 本地预览，没有提交 Maker 或远端构建，也没有生成新的 Android 安装包。

## 建议执行顺序

1. 从正常初始局开始，先测正常 HUD、手工制作、交付和区域切换。
2. 在车间测样例产线、缓存、建造、管理与布线。样例被拆坏后可在完成页重开，或关闭窗口后使用桌面 Demo 启动入口重新开始。
3. 测暂停、设置、统计和三天循环；最后一次重开检查初始状态。
4. 在手机上重新执行核心操作，并增加多指、安全区和后台中断专项。
