# R4：传送带编辑与建筑投影验收修复

日期：2026-10-18（Asia/Shanghai）。对应用户本轮“第二轮2/3、a、b、c”反馈；不是新开发阶段。用户最终复验尚未进行。

## 行为调整

| 反馈 | 修复后 |
| --- | --- |
| 键盘选取方向与画面不一致 | 非编辑状态WASD按屏幕上/左/下/右寻找空间目标；无该方向目标时保持当前选取，不循环点序号或切换类型 |
| 移动后反向操作引出新带 | F开始一次编辑时保留原路径与逻辑控制点；连续移动按累计位移重算，反向返回同坐标可恢复原形，拐点合并不导致后续移错点 |
| 转弯节点移动不联动、出现360度转弯 | 调整相邻直线约束，端口保持离散贴边；编辑时擦除重叠折返及闭合绕行、化简冗余节点，仍保留正常建筑/边界冲突检查 |
| a 建筑投影固定 | 场景左键固定预览，鼠标移动不带走投影；空白处再次左键解除固定。点击投影本身或已有建筑保持固定；WASD可微调；最终实际建造仍需确认按钮 |
| b 选择B时无实时预览 | 选A后持续显示A边框到鼠标/键盘光标的路径；指到B时贴合其边框。临时预览不选定B、不运输、不允许直接确认 |
| c 放带后退出到建筑首页 | 成功后清空当前A/B、编辑快照和临时预览，直接进入下一轮选A。右键/取消仍可回首页 |

快速拖动另做了输入修正：从引擎`MouseButtonDown`事件保存真实按下坐标，拖动终点使用当前坐标，松开时也应用最后位移。UI命令拥有该输入帧，避免按钮点击穿透到场景。
