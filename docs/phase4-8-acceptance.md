## 准备与判定

使用当前 Windows 本地窗口，标题为“自动化汉堡工厂 · Demo V0.1”。正常交付版不生成测试物品，不加速时间，不自动操作，也不打开调试菜单。HUD 显示 Day 1/3、05:00 起的倒计时与今日统计。若当前窗口已经运行一段时间，可先检查页面，再用暂停菜单结束当天、结算进入下一天，直到 Day 3 完成后选择“重新开始”，获得干净 Day 1；不要把此准备过程算作正式验收。

建议按下面的 A→B→C→D 顺序做一整轮，约 30–50 分钟；记录耗时与截图不计入营业时间时，先按 ESC 暂停。Day 1 时间归零后仍可继续做设备和建造测试；因此不用为了赶五分钟缩减测试。Day 2 保留真实五分钟进行订单与归零验证。Day 3 完成高需求交付、跨日统计与结束流程，最后重新开始并退出窗口。

填写 [结果表](phase4-8-results.md)：通过 / 失败 / 未测 / 阻塞。随机订单未出现需要的数量，标“未测”并补测，不能   当作失败，也不能记通过。没有空间构造删除失败等极端边界时，保留“未测”；对应自动边界检查仅作补充证据。

每个失败至少记录：用例编号、当天/剩余时间、操作、手持物、订单编号及需求、设备状态、预期、实际、是否可复现。发现退出/闪退、物品消失、订单超额扣除、统计或跨日错误时，先停止该条并记录；不要继续填它依赖的条目为通过。

## A · Day 1：生产、昵称、建筑（阶段 4–5）

先用地图顶边三种无限原料点、煎肉铁板及手工组合台准备熟肉。所有工作台取出须空手；Q 可腾出手，原料点持物 F 会把旧物放附近地面再换新原料。场景左侧初始有两台普通自动设备，可移动/删除；不是测试产物。

| 编号 | 操作与前置条件 | 必须观察到的结果 |
| --- | --- | --- |
| A01 | 检查俯视地图，移动并拖动中键、滚轮缩放；靠近和离开原料点、固定台和自动台 | 镜头不能旋转，比例与此前恢复版本一致；建筑昵称靠近显示、离开隐藏，依附建筑，不随拖动脱离。世界字的屏幕间距随缩放变化；不要求每个缩放下恒定 5px |
| A02 | 地面放两种物品；持其中一件对另一件 F，再持物对原料点 F | 地面交换旧物留在原位置；原料交换旧物落附近有效地面；对准地面物品名称仍在屏幕上侧居中，不使用建筑世界标签 |
| A03 | 手工放生肉，松 F 后重新长按约三秒；中途松手一次再继续 | 中断进度归零、生肉保留；连续三秒后成为熟肉；自动取料不把放入那次 F 当作煎肉时长 |
| A04 | 给自动烹饪台分时投入三块生肉；观察剩余时间；满槽时尝试第四块 | 三槽各自三秒，投入时间不同则完成时间不同；第四块仍在手中；熟肉仍占原槽 |
| A05 | 空手从尚未完成的槽取出生肉，再投入 | 没有熟肉时，生肉后进先出；重新放入从三秒起；有熟肉时仍优先最早完成熟肉 |
| A06 | 三槽中保留熟肉和生肉，空手多次 F | 优先最早完成的熟肉，不能随机取未熟肉，也不能跳过仍占槽的熟肉计算容量 |
| A07 | 自动组合台放胚、生肉、菜；空手取回；换熟肉 | 错误生肉占肉槽，明确提示缺熟肉，不合成；空手优先取回错误生肉；正确配方齐全才加工两秒 |
| A08 | 自动组合台加工期间尝试放入/取回；加工完取出 | 加工中拒绝，材料不丢失；完成有一个汉堡，空手优先取出；生成时自动统计 +1，取出不再次计数 |
| A09 | 留一份成品，缓存下一批胚/熟肉/菜，等待超过两秒，再取走成品 | 未取成品时下一批不加工；取走后才启动两秒；成品容量仍为一份 |
| A10 | 用自动煎肉得到熟肉，最终在手工组合台组装一份 | 手工生成即时完成；计为手工汉堡 +1，自动组装计数不增加。手工+自动=制作总数 |
| A11 | B，键盘选型→F进入预览→WASD/R→F确认；再建第二台 | 预览可直接调整并确认；1m网格、90°旋转；免费且可连续建造；非正方形占地随旋转改变 |
| A12 | 鼠标悬停/点击另一类型，在空地左键确认；右键取消另一次预览 | 鼠标选型、鼠标定位、滚轮旋转、左键确认工作；一次点击不同时完成选型和落地；取消不生成新建筑 |
| A13 | 试放在固定台、入口禁区、已有建筑、玩家及地面物品上；再试越界和超过玩家五格的合法空地 | 冲突/越界红色投影拒绝；距离超过五格仍可放置、选择、移动、删除；普通F交互范围保留 |
| A14 | B→Tab/F 或鼠标管理；选空闲建筑移动/旋转，ESC 取消；再重新移动并确认 | 取消保留原位置、朝向、内容；确认后在新位置，昵称仍跟建筑；固定设施不能移动 |
| A15 | 先给设备放入未加工材料/成品，再移动并删除；删除时手里保留一件物品 | 移动保留内容；删除把内容放合法附近地面，不吞掉；Q 不丢弃手持物。当日制作计数不因删除成品机器而减少 |
| A16 | 设备正在煎肉或组装时尝试管理移动/删除 | 拒绝，不丢进度、材料或建筑 |
| A17 | 可选极端项：用物品/建筑堵住设备周围合法落点，再删除有内容设备 | 无空间则删除取消，建筑及全部内容仍在。无法人工构造时标未测，对照自动边界证据 |
| A18 | 打开 B 菜单和收银界面各停留十秒 | 玩家不移动，日计时和自动加工继续；关闭后恢复普通交互 |

此部分若超过五分钟，未完成订单会清除，但机器与建造继续可用。完成后准备跨日样本：手持一件、地面一件、交付区至少一份汉堡，机器留材料或熟肉，移动一台设备。再执行 B01–B05 进入 Day 2。对需要加工中样本的 B02/B04，先清空一格后重新投入生肉，立刻暂停，留约 1–2 秒进度。

## C · Day 2：订单、交付、真实计时归零（阶段 6–8）

按当前订单清单选择需求为两份的订单做部分交付。订单随机，若五单全部一份，完成其中一份腾位再等待 5–15 秒；不能凭空改需求。如果 Day 2 到时仍没有两份订单，将 C05 留待 Day 3 的两份或三份订单补测。

| 编号 | 操作与前置条件 | 必须观察到的结果 |
| --- | --- | --- |
| C01 | Day 2 开始后观察首单和后续订单；暂不交付直到五单 | 首单也等待 5–15 秒；数量仅 1–2；最多五单，满单等待不会继续加；HUD 编号/需求/进度正确，无订单独立倒计时 |
| C02 | 持汉堡到交付区 F，空手 F 取回；放满五份，再尝试第六份和非汉堡 | 只接收汉堡、容量五份；第六份仍在手中；非汉堡不消失；取回减库存、得到一份 |
| C03 | 打开收银，不选订单；随后清空交付库存选单 | 开界面不自动选单；未选单或库存空不能交付，按钮状态与实际拒绝一致 |
| C04 | 时间尚未归零，在收银点“结束当天”或按 E | 不能结束、不跳结算、不清订单；日时间和机器仍运行 |
| C05 | 对两份需求订单，库存仅一份，主动选单交付 | 进度 1/2，订单还在；完成订单统计不增加；库存扣一份；不自动改选其他订单 |
| C06 | 补足汉堡完成该订单；库存额外多放一份 | 只扣剩余需求，余汉堡保留；完成计数 +1；订单移除、选择清空；不能把余汉堡自动交给下一单 |
| C07 | 分别键盘选单 F 交付、鼠标点行再交付；完成满单中的一单 | 两套输入有效；满单腾位后重新等待 5–15 秒，不能立即补一单 |
| C08 | 在五分钟内记下制作/完成数量；最后保留未完成或部分交付订单、库存及手持物，观察 00:01→00:00 | 每天真实五分钟（暂停时间不计入）；归零立即停止生成、清全部未完成订单及选择；没有失败、惩罚或虚假完成计数；库存和持物保留 |
| C09 | 归零后等至少 20 秒，移动、整理、放建筑并制作一份汉堡 | 不再生成订单；仍可操作并加工；此份汉堡仍计入 Day 2 统计，不自动进入结算 |
| C10 | 归零后打开收银，点击“结束当天”或按 E | 结束入口可用，进入 Day 2 结算；数字与记录一致，清除/未完订单不计完成；停留不会继续加工 |
| C11 | 点击进入下一天，复核关键样本与 Day 2 结算记录 | Day 3 五分钟；当天计数和订单清空重置；库存、地面、手持和建筑继续保留 |
