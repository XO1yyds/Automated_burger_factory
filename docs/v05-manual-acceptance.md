# V0.5 下单式自动化人工验收

日期：2026-10-19。当前状态：开发自检已有证据，正式用户验收待进行；以下勾选均未代填通过。

## 使用方法

建议先完成第一轮基础流程，再做第二轮边界测试。每项可记录：通过 / 不通过 / 未测；反馈请带编号、实际操作、结果和截图。不同轮次可重新开始，避免满库或断网影响下一项。

Windows本地预览是当前验证环境。手机目标为小米14、安卓15；Windows鼠标测试不能替代安卓触控真机测试。不包含存档，重新开始会清空当前进度。

**验收入口**：源码的 `RUN_V05_VISUAL` / `RUN_V05_RUNTIME` 已均设为 `false`。加载最终刷新版本后应从店铺第1天普通开局，不自动传送、不自动下单。若仍开局打开车间终端，说明窗口还在使用临时自检版本，应刷新。本清单不要求用户修改代码。

电缆端点是建筑顶部锚点或现有线上的网格点。调整页可切换直角走线顺序，在光标位置添加拐点，选择后拖动或WASD移动；点击“确认连接”才落地。新增传物电缆不替代实体传送带。

## 第四轮：小米14 / 安卓15

以下均需真实手机环境，不以Windows鼠标模拟通过代替。

- [ ] 横屏安全区内，终端页签、返回、提交按钮不被挖孔/系统手势遮挡。
- [ ] 列表滑动不误提交、不误取消；顶部页签和底部提交入口可见。
- [ ] 数量±1/±10、目标选择、任务取消的触控目标易点中。
- [ ] 电缆选起点、终点、添加/拖动拐点、确认、返回能完成；双指场景手势不抢节点。
- [ ] 离开/返回应用后按既有失焦暂停规则处理，移动与交互没有残留按住状态。
