# V0.4 UI美术与易读版型 · 人工验收

基于V0.6十天经营玩法；本轮验收UI，不需要重新验证全部生产数值。验收状态由玩家填写，未勾选不代表失败。

## 使用方式

从原有桌面启动器进入，先检查标题存档卡，再继续已有进度。不要为检查UI覆盖原经营存档。高阶页面随原有天数解锁，尚未解锁时记“待对应天数检查”。

结果可填：通过 / 问题 / 暂未检查。反馈问题时注明页面、Windows或手机、UI缩放与操作步骤。

## 完成条件

- 当前可用页面没有遮挡主操作、无法阅读或无法返回的问题。
- 原有取物、生产、建造、物流、下单、交付和存档规则没有因UI更新改变。
- Windows和Android结果分别记录；未经真机操作不勾选U20。
- Agent发现的待修问题以 `v04-ui-art-development-status.md` 为准，不能仅凭此表存在就视为开发已完成。
