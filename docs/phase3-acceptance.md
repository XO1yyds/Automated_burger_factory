# Phase 3 · 手工生产验收

日期：2026-10-14（Asia/Shanghai）。状态：手工生产已实现，89 项 Runtime 检查通过，等待用户操作验收。Phase 4 自动工作站尚未开始。

## 本阶段规则

- 三个无限原料点、持物交换、Q 丢弃、地面物品上侧居中对准名称、镜头和地图布局保留。建筑/原料点名称改为靠近时显示在建筑屏幕上边缘正上方 5px；离开隐藏，无需面向。
- 移除 Phase 2 中央五份临时样品。初始手持、地面、铁板和组合台均为空；熟肉和汉堡仅由生产链生成。
- 铁板只接收一块生牛肉饼。持物 F 放入后手中清空；放入的那次长按不开始烹饪，需松开再长按 F。
- 空手、面向铁板且在交互范围内，连续长按 F 三秒变成熟肉。松开、改变有效目标、离开范围或失去窗口焦点会清零进度，肉留在铁板；持物或按 Q 时不推进。生肉不能取出，熟肉需要空手再次按 F 取出。
- HUD 显示铁板内容与剩余时间；铁板上的色块由生肉颜色变为熟肉颜色。熟肉不会焦糊或自行消失。
- 组合台只接收汉堡胚、熟牛肉饼、生菜片各一份，任意放入顺序。正确三种齐全立即消耗材料，产生一个汉堡；无需长按和加工时间。
- 生肉/汉堡和重复材料拒绝放入，原物仍在手中。生肉提示“缺少熟牛肉饼”。手工组合台不接受错误生肉占槽；允许占错肉槽属于 Phase 4 自动组合台规则。
- 组合台有汉堡时拒绝继续投入；空手 F 取出成品。缺料时，空手 F 按汉堡胚 → 熟肉 → 生菜的固定顺序逐份取回，无新选料界面。
- 台面以色块显示内部物品，HUD 分别显示材料数量与成品。生成时更新内部手工制作计数，为 Phase 8 统计预留来源，本阶段不实现跨日结算。
- 工作台需要空手取出，不套用原料点/地面交换规则。

## 人工操作流程

1. 初始中央地面没有样品，手持和两个工作台为空。
2. 从右上生肉点按 F 取一块生肉，走到煎肉铁板前按 F 放入。
3. 继续按住这次 F，确认不会开始；松开，再长按。计时未满三秒时松开，确认显示重新回到三秒，生肉仍在台上。
4. 再次长按，在未完成时走远或转向，确认进度归零；回到铁板前，重新连续长按三秒，确认熟肉完成。
5. 松开 F，再空手按 F 取熟肉，走到组合台按 F 放入。
6. 分别取得汉堡胚、生菜片并放入组合台，确认第三种放入时立即生成一个汉堡，原料消耗，手持为空。
7. 空手 F 取出汉堡，Q 放地上，再 F 拾取，确认不丢失、不复制。
8. 组合台已有汉堡时尝试投入新材料，确认拒绝且原物留在手中。
9. 分别测试重复材料、生肉放入、缺料时取回，确认失败不丢物；原料点/地面持物互换依然可用。
10. 检查地面物品上侧居中名称、台面色块、材料 HUD、滚轮缩放和中键平移。靠近建筑时检查其小字名称：位于屏幕轮廓的上方 5px，平移或缩放不偏移，走远隐藏。建筑名称几何验证另见 [建筑标签修复证据](building-label-evidence.json)。
