## 代码与边界

- `scripts/Factory/UIState.lua`：UI阶段/布局/偏好策略。
- `scripts/Factory/InterfaceV3.lua`：urhox-libs/UI组件树；原Interface入口转发到新版。
- `scripts/Factory/UIController.lua`：共享动作、场景输入、模式与生命周期衔接。
- `scripts/Factory/TouchInput.lua`：触点所有权、摇杆、双指镜头；不生成合成键盘事件。
- `scripts/Factory/UIPreferences.lua`：仅UI偏好，使用文档规定的项目/用户隔离文件API，不保存游戏进度。
- `Phase1.lua`接入新版，保留原生产/物流服务；ConveyorWorld补充真实冲突格标记。
- 原StageChecks/LoopChecks迁移到新交互，并使用车间设备；未靠关闭受影响检查掩盖H01。

固定正交相机与场景比例保持；没有改引擎库或引擎资源。普通试玩版全部QA/临时场景开关为false。
