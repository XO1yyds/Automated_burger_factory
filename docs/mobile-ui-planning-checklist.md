状态：历史通用模板，保留作覆盖范围参考；当前不需要再次填写。最新依据为[已审阅补全需求](ui-next-stage-requirements-draft.md)及[统一默认布局](ui-layout-defaults.md)，H01～H04已确认，用户已授权按当前清单开发V0.3；本文件只作历史模板。

## 1. 填写说明

- 空白处直接填写；没有决定的内容保留“待定”，不视为默认同意推荐方案。
- “建议”是讨论起点，不是已确认需求。
- 总清单“本轮安排”填写：制作 / 后续 / 不需要 / 待定。
- 每个本轮制作项目至少明确：显示内容、出现条件、操作方式、异常反馈、验收标准。
- 本文确认前只进行策划整理，不据此直接修改游戏功能。
