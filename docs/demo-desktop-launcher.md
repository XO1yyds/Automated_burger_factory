# Demo 桌面启动入口

- 桌面快捷方式：`自动化汉堡店 Demo.lnk`。
- 项目内启动脚本：`launch-demo.ps1`。
- 双击快捷方式检查本项目预览状态；已运行时复用，确认停止后调用官方 `preview start`。
- 启动终端完成后自动关闭；失败时保留错误并等待回车。
- 使用已安装的 Node 与 Maker 0.0.36；不自动安装、升级、提交、推送或远端构建。
- 快捷方式仅为本机项目入口，不是独立打包游戏；需保留项目目录、Node 和 Maker Runtime。
- 项目目录移动后需重新创建快捷方式。Maker 版本迁移后需核对脚本中的版本路径。
- 进程启动不等同于玩法验收或完整就绪检查通过；原有资源/DLL告警不由本脚本修复。
