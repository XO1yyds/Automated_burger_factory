## 1. 本轮范围

- 用户列入R01～R14：正常HUD、手机输入、分类栏、建筑放置/管理、设备检查、物流三阶段、异常反馈、缓存台、返回导航、收银/暂停/结算/完成、操作教学和设置。
- R15不做正式界面美术、生成图标或场景资产替换。实现R01～R14必要的白模按钮、文字占位图标、面板和选中状态属于这些模块的基础工作，不按R15删除。
- 不增加节点删除、直线/转角专用工具、多带型、自动补线、运行中改线、金币、背包或完整存档系统。
- 保留现有垂直正交镜头、世界比例、设备尺寸、配方、加工时间、运输规则、暂停与日循环；建造临时缩放仅改变观察范围。
- 手机安卓横屏；固定摇杆为默认，设置中可切换浮动摇杆。Windows保留键鼠。默认双端UI表示同一套按钮可触摸/点击并显示小型快捷键标记，不生成两套重复操作栏；摇杆也保留，可通过设置切换显示模式。
- H01确认的地图变更：下一阶段从店铺初始配置移除自动烹饪台`auto_grill`和自动汉堡组合台`auto_assembly`，初次启动及第三天重开均不恢复这两台。保留店铺手工煎肉铁板、手工组合台和车间`ws_cooker`/`ws_assembler`，店铺不开放建筑首页或设备管理例外入口。相关原回归夹具应改为车间设备测试，不靠关闭检查掩盖变化。V0.3已修改启动及重开配置，并以车间设备完成回归。
- 真机验收目标已明确为小米14、Android 15；这不是已测结论，也不代表最低支持系统或其他设备兼容承诺。

### 白模统一样式

- 中性灰背景/边框，文字深浅对比清楚；物品用文字和简单位形占位，不生成正式美术。
- 按钮状态：可用、当前选中、按下、禁用。禁用不仅灰色，也保留原因文字；手机不依赖悬停。
- 合法绿色加“可放置”，非法红色加“不可放置/原因”；选中用外框及“已选”，受限用短横锁定标志及方向说明，不仅用颜色区分。
- 字号推荐：标题22、正文18、辅助16逻辑单位；真机可读性未验收，设置提供UI缩放0.9～1.2，放大后优先滚动/折叠。

## 4. 显示优先级与唯一状态

正常游玩是基础状态，不表示它盖过正在操作的模式。用户“进入A阶段后不显示其他阶段信息”统一解释为：每时刻只有一个活动操作模式拥有场景动作、目标卡及提示。

1. 暂停/结算/完成等生命周期遮罩拥有最高输入优先级。
2. 暂停内的统计/设置/确认子页只显示该子页内容，返回回暂停或其父页。
3. 订单展开、收银、缓存选物、建造/管理/物流阶段互斥；开启一个先关闭其余操作页。
4. 当前模式的选中对象、工具和原因只服务于该模式；传送带选A时不出现选B、调整或自动设备生产详情。
5. 只有正常游玩才自动显示靠近且面朝的设备检查；同范围手动点选优先于自动目标，移动/失效解除手动选择。
6. 时间、手持和暂停是跨场景共享信息，不属于另一操作阶段；生命周期遮罩中统一隐藏/弱化，禁止重复一套HUD。

卡片原则：每次至多一个情境信息卡。卡片依相机世界基向量、正交高度、缩放和UI比例投影到建筑上边缘锚点；默认居中上方5逻辑单位，贴边只相对锚点换边。锚点出屏或无空间时隐藏，禁止独立钳在屏幕边缘。进入任一新模式清前一模式临时卡、悬停、拖动与候选状态，不清除真实库存、产线或有效的手动选单。

## 5. 触控与确认统一规则

- 角色摇杆位移小于半径15%为死区；15%～85%为原4m/s步行，85%以上为8m/s奔跑，退到75%以下回步行，松手停止。阈值为推荐值，需真机调手感。
- 支持摇杆+点击交互/放下、摇杆+独立按住加工（离开目标导致加工中断仍沿原规则）。
- 双指平移/捏合必须由两个都从非UI、非摇杆区域起始的触点组成；摇杆手指不计入镜头手势。
- 同一组双指以中心位移平移、间距变化缩放，不支持旋转；缩放沿用现有0.8～2.5界限。进行建筑/控制点拖动时不允许镜头手势同时争抢，需先结束拖动再用双指调整。
- 触摸所有权从按下固定到释放：导航/UI > 摇杆 > 当前选中拖动对象 > 普通场景；UI滚动超过8逻辑单位后取消点击，拖动超过阈值后松手不算另一次点选。
- 手机/Windows按钮均一次完整点击执行明确动作；按下不执行，松开在有效区域且未变成拖动才触发。键盘选中同一控件后F/Enter执行；快捷键仍走同一动作门槛，输入去重，不能一次点击同时选卡、放置或交互。
- 单指点投影后拖动，使用抓取偏移避免跳到中心；拖动时显示手指上方约32逻辑单位的落点标记，不凭空加新的投影坐标偏移。松手固定，点空白解除并重定位，仍需主确认摆放。
- 端点/转角先选再拖，单段在电脑和手机均静止按住0.35秒后拖动，提前移动超过8逻辑单位则取消本次长按，松手不摆带。热区至少48；端点/转角优先于线段，重叠时先选择屏幕距离最近者，同距优先当前选中，不使用全局索引方向循环。
- 不显示上下左右微调按钮。WASD仍按视觉方向选节点/路段；端点/转角保留F进入编辑及WASD逐格调整，单段仅长按拖动。试算受限显示原因，不把衔接格后的第一格一律硬锁，不自动补线/重连；反向回原坐标恢复原预览。长按等待期间占用对象触点，第二指不能接管或启动镜头手势。
- 建造时角色透明但仍占位；仅改变显示，不关闭碰撞或将其占用格变成可摆放。
- 进入建造只保存一次相机位置/缩放，临时视图缩放为进入前×0.9并限制在现有范围；子模式不重复缩放；退出建造恢复进入前相机状态。
- 切后台/失焦释放摇杆、按住加工、拖动及所有触点，冻结模拟。回前台停留暂停，用户主动继续；预览保留最后网格位置，未确认的实体不写入。

## 6. 统计、文案与反馈

| 类别 | 字段/规范 | 边界 |
| --- | --- | --- |
| 运行统计·当日 | 当天/剩余时间、完成订单、待处理订单、手工/自动/总汉堡制作数 | 读取现有状态，不把拾取/转运当制作 |
| 运行统计·当前产线 | 各类现存设备数、实体带数、带上物品数、缓存占用/总容量、交付库存、累计交接件次 | 写清“全项目/当前时刻”；不凭空提供效率、每分钟产量或历史吞吐图 |
| 运行统计·结束记录 | 已结束各日订单与手工/自动产量，当前局实际报告的拆除损失明细 | 损失仅记录真实事件、无事件显示无记录；重开清本局记录，不承诺退出后保存 |
| 设备说明 | 建筑真实尺寸、槽位/容量、用途、配方和加工/运输规则 | 放在统计页的“设备说明”分区，不新增悬浮静态说明卡 |
| 普通反馈 | 成功约2秒、失败/限制约3秒 | 去重，不用自动完成提示持续刷屏，必要时合并同类 |
| 拆除损失 | 至少4秒，列实际物品及数量，可在统计查看当前局记录 | 优先级高于普通成功，后续普通Toast不覆盖未读的重要损失 |
| 原因优先级 | 对象失效/模式不允许 > 跨区/越界 > 端口能力或占用/闭环 > 建筑重叠 > 带重叠 > 无法保持衔接 | 当前首要原因显示在F，冲突位置同时标记；其他原因可在同一卡片逐行显示，不要求长弹窗 |
