# 可操控员工：剩余8帧动画需求清单

日期：2026-10-19。用途：后续角色动画制作、修订与验收。

**用户已确认：每组8帧，保留现有手绘风；不是改成8bit像素风。**

本清单只整理需求，不启动图片生成或游戏接入。Maker生成目前按用户要求停用；后续制作工具与实际来源如实记录，不将推理模型名称当作图片工具返回的型号。

## 1. 范围与当前状态

- 一名可操控员工，正面、左侧、右侧、背面四个方向。
- 每个“方向×动作”为一组，每组8张完整人物帧。
- 完整目标：8类动作×4个方向＝32组，共256帧，不含过程修订和废弃版本。
- 最新四向空手跑动已有32帧候选，均待人工验收，尚未接入游戏。
- 其余7类动作目标为28组、224帧。已有旧素材可审核或修订，**不代表224帧全部缺失或必须重新生成**。
- 空手走路、持物走路、持物奔跑共12组已有明确步态问题，优先处理。
- 所有动作的素材验收、运行接入、手机验收分别记录，不能互相替代。

参考：[原角色开发计划](v04-character-development-plan.md)、[现有制作进度](v04-character-animation-progress.md)、[最新四向跑动审核入口](v04-run-depth-review.html)。

## 5. 持物、挂点与遮挡共用规范

- [ ] 覆盖现有五类物品：汉堡胚、生牛肉、熟牛肉、生菜、汉堡。
- [ ] 本批不自动新增五类物品的正式美术，先复用当前物品做挂点验证。
- [ ] 每个持物动作、每个方向的8帧均有对应挂点；记录归一化坐标，不能只校准首帧。
- [ ] 正面物品在躯干前，必要时由手/前臂遮住物品边缘。
- [ ] 背面物品在身体前方，允许被躯干遮挡；不为展示物品把手画到后背。
- [ ] 左右侧物品位于对应身体前方；与人物共同缩放。
- [ ] 完整人物始终保留；若确需额外手部遮挡层，只用于遮挡物品，不切割头部制造动画。
- [ ] 交换、放下、销毁、缓存取放后立即按真实手持状态切换，不被动画锁住。

## 6. 游戏接入需求（资产验收后执行）

- [ ] 屏幕下/上/左/右分别显示正面/背面/左侧/右侧；斜向选择主轴并避免方向抖动。
- [ ] 停止移动保留最后朝向；平移/缩放镜头不改变角色朝向。
- [ ] 保留现有步行4米/秒、奔跑8米/秒；键盘Shift与手机原有奔跑操作不变。
- [ ] 动画按时间推进，不绑定游戏每帧；低帧率不改变角色速度、生产速率或思考阈值。
- [ ] 状态优先级沿用：真实持续加工→移动→持物待机→思考→空手待机。
- [ ] 暂停/结算冻结动画；恢复重新判断状态，不恢复旧按住输入。
- [ ] 建造、物流编辑等禁止移动时显示相应待机；建造的原有角色淡化规则保留。
- [ ] 切区、重开、失焦与目标删除清理旧动作引用；资源缺失有回退与日志。
- [ ] Windows先自检；小米14/Android15横屏另做真机验收，不以桌面检查替代。
