## 镜头

![图 1：纯俯视正交参考](references/camera-topdown.png)

- 正交相机垂直向下，俯角 90°，水平角 0°，无透视远近缩放。
- 不允许旋转镜头。滚轮缩放，中键拖动平移；平移范围限制在房间附近。
- 屏幕右对应 +X，屏幕上对应 +Z，W/A/S/D 对应屏幕上/左/下/右。
- 保留基础几何体和物理系统，呈现为纯俯视平面白盒；不复制参考图的正式美术。
