## 2. 基础传送带

### 2.1 结构与物品

- “线性”指一条连续带不分叉，拥有一个输入端和一个输出端；允许直角转弯。
- 合并、分散必须通过接口，中途接入需先拆分并设置接口。
- 传送带具备主动取料和运输能力，不具备物品过滤能力。
- 同一条带可混运不同物品；不得根据物品种类选择路径、自动改道或丢弃。
- 玩家不能直接对传送带上的物品按F取放。
- 物品具有真实运输时间、可见实体和有限承载空间；不沿用旧的跨设备瞬时转移。

### 2.2 参数

| 参数 | 规则 |
| --- | --- |
| 基础类型 | 本期仅制作基础传送带；保留类型扩展位置，后续再加入新类型 |
| 网格 | 沿用1米建造网格 |
| 带宽 | 0.8米 |
| 单格几何 | 直线部分长度1米、宽0.8米；转弯也需要合法占地 |
| **移动速度** | **0.5格/秒**，当前1米网格下等于0.5米/秒；不是“0.5件/秒”的独立定时发货规则 |
| 传送带容量 | 占地n格可承载n件物品；接口占地不额外算作传送带库存 |
| 物品顺序 | 同一路径先进先出，不超车、不倒序、不瞬移 |
| 长度与控制点 | 不设玩法上的最大长度/控制点数；仍受地图、占地和禁止环路规则约束 |
| 跨区 | 禁止 |
| 自连及环路 | 禁止，包括通过接口或缓存台等端点形成的有向物流闭环 |
| 启停 | 移除旧全场连接启停操作；合法连接按需求运行，暂停/结算按第10节冻结 |

“n格可承载n件”属于容量规则；物品最小间距和端口连续交接节拍的落地口径见第12节D04，不用移动速度擅自替代其他参数。

### 2.3 交接、堵塞与设备规则

1. 输入端从相连建筑的合法输出中主动取一件，先检查带首是否有空间。
2. 物品到达带尾且目标接收成功后，才转移所有权；目标拒收时保留在带尾。
3. 下游满载或材料不合法时，带尾堵塞，后续物品排队；堵塞逐步向上游传递。
4. 容量不足时停止取新物，不能越过前方物品或把物品传到另一条不相干路线。
5. 设备自身的配方、加工锁定、容量、合法输出仍有效。“不筛选物品”不表示机器必须接收错误材料。
6. 因此，填写版中“机器进入非法物品”统一为：错误物品被送到机器输入端，但机器拒收时停在带尾，不默认进入机器库存。
7. 正常运输数量守恒。第9节规定的拆除溢出销毁是明确例外，必须报告实际损失。

## 3. 普通十字接口

### 3.1 端口与被动性质

- 作为建筑类型，占地1格，具有上、下、左、右四个端口。
- 每个端口最多接一条传送带，并且一次只分配一个方向。
- 端口输入/输出身份由接入传送带的方向决定，不预设永久进出面。
- 不主动抓取设备或地面物品，不主动跨空隙取料、推料，不具有独立运输速度。
- **不另设物品缓存**。无法完成交接时，物品仍归上游传送带所有。
- 仅承担收束、分散和仲裁；没有接入传送带时不传递物品。
- 不直接与相邻建筑隔空交接，建筑与接口之间也需要传送带。

### 3.2 合法组合与施工状态

| 输入数 | 输出数 | 施工时是否可存在 | 运行规则 |
| --- | --- | --- | --- |
| 0 | 0 | 允许 | 孤立接口，显示未接线 |
| 0 | 1～4 | 允许 | 允许未完成布置，但不运行、不主动产出 |
| 1～4 | 0 | 允许 | 允许未完成布置，但不接收物品进入接口 |
| 1 | 1 | 允许 | 正常一进一出 |
| 2 | 1 | 允许 | 合并，剩余一口空闲 |
| 1 | 2 | 允许 | 分流，剩余一口空闲 |
| 3 | 1 | 允许 | 三进一出合并 |
| 1 | 3 | 允许 | 一进三出分流 |
| 2 | 2 | **禁止** | 普通十字接口不承担两进两出 |
| 超过4口或同口重叠 | 不适用 | **禁止** | 端口总数及占用检查失败 |

“禁止单边连接”已被本轮接受的建议替换为“允许施工，连接不完整时不运行”，避免第一条带无法铺设。预览中的非法组合可显示提示，但不能确认成有效连接。

### 3.3 调度与吞吐

- 多输入请求采用轮询调度；多输出采用轮询分配。
- 各输入持续有货且下游畅通时，不得让某条输入长期饿死。
- 分流不设置按品类的路线或过滤条件；跳过堵塞口只依据相邻传送带的空间可用性。
- 临近接口的输出带已满时，视该输出口堵塞；若仍有其他可用输出口，可以跳过堵塞口继续分配。
- 不另设接口速度或额外吞吐增益，采用输入/输出能力的木桶短板规则。

| 场景 | 吞吐上限约束 |
| --- | --- |
| 三进一出 | 不超过单个输出口相连传送带的有效接收能力，也受输入实际供给限制 |
| 一进三出 | 不超过单个输入口相连传送带的有效供给能力，也受输出实际空间限制 |
| 一进一出 | 受输入、输出两侧较弱一侧限制 |
| 一般情况 | 上限受输入总供给与输出总接收中的较小值限制；实际还会因堵塞下降 |

该规则是上限约束，不意味着接口可把物品瞬间送过整条下游带。交接后的移动仍由对应传送带完成。

## 4. 隔离接口

### 4.1 类型与规则例外

隔离接口占地1格，可在放置时旋转，内部含两条互不干扰的配对通道。它是普通十字接口禁止2入2出的明确例外，不进行通道间的合并、分流或混料。

| 类型 | 未旋转时的通道配对 | 旋转效果 |
| --- | --- | --- |
| 直通隔离接口 | 上↔下、左↔右 | 配对随建筑旋转 |
| 转角隔离接口 | 上↔右、下↔左 | 配对随建筑旋转，可得到另一组转角配对 |

“↔”仅表示端口配对，**不代表同一通道可同时双向运输**；实际输入与输出由接入传送带方向确定。

### 4.2 独立运输与合法性

- 两条通道各自一进一出，禁止串线、复制物品或把一个输入送到另一组出口。
- 不主动运输、不增加独立速度，**每条通道均不另设缓存**。
- 各通道受对应输入/输出较弱一侧限制，不把两通道合成共享运输速度或共享库存。
- 允许先布置未接完整的通道；不完整通道不运行，不影响另一条已合法接通的独立通道。
- 同一配对内两端都为输入或都为输出时，不构成可运行通道；具体提示不应伪称连接成功。
- 接口内部独立通道可以共处一格；普通带的同格交叉、平行重叠和堆叠仍禁止。
- 放置、改向预览及吸附恢复时，应按独立通道判断物流路径，不能把两通道错误合成一个可混流节点。

## 5. 缓存台

### 5.1 建筑与库存

| 项目 | 规则 |
| --- | --- |
| 占地 | **2×4格**，沿用1米网格 |
| 容量 | **6件物品**；占地8格不表示容量8件 |
| 物流能力 | 可作为传送带的输入端目标，也可作为传送带的输出端来源 |
| 保存 | 传送带运入后保存在缓存台；与机器成品槽、店铺交付库存区分 |
| 输出驱动 | 与设备相同，由输出侧传送带主动取料；不由缓存台隔空主动运输 |
| 类型选择 | 缓存台不因本期需求新增按物品类型筛选输出的配置 |
| 外观与选择提示 | 在场景中的缓存台上展示物品和当前选择，不打开新的库存界面 |
| 移动/旋转 | 使用建筑管理；先拆相关带，再按既有建筑规则处理 |
| 空位与输出顺序 | 见第12节D01/D02，未擅自确定 |

### 5.2 空手取物流程

1. 玩家空手与缓存台交互，进入缓存台选取阶段。
2. 不打开新界面；在缓存台本体上显示当前选择。
3. 选取阶段WASD控制物品选择，玩家角色不随WASD移动。
4. 选中有效物品后，F确认并取出到手持栏。
5. 鼠标左键点击库存槽直接确认取出/交换/空槽存入，成功后退出选择。ESC与右键均取消选择。
6. 右键回退/取消当前选取阶段，不顺带丢弃手持物或进入建筑拆除。

### 5.3 手持物交换流程

- 玩家有手持物且已有有效选中项时，与缓存台交互应交换手持物与该选中物品。
- 首次交互没有选中项时，**先进入选取阶段，再确认交换**，不得默认第一件并立即交换。
- 交换成功时，原手持物进入所选库存位置，原选中物品进入手持栏；物品总数和实体所有权保持一致。
- 若确认时选中物品已被输出带取走或状态变化，需要重新校验；不能复制、删除或悄悄交换成另一件物品。
- 没有有效选中物品时不自动执行交换。允许选择空槽后手动存入手持物，空手选空槽不改变库存。

### 5.4 与传送带并发

缓存台向输出带按后进先出（栈）输出。玩家选择期间继续输出；选中物被取走后提示重新选择。无论最终选择何种方案，确认取物/交换必须使用当前有效状态，不能使用进入选取阶段时的旧快照扣除物品。

## 6. 建筑端点、网格与占地

### 6.1 建筑端点

- 建筑边框上的任意合适位置均可作为输入/输出端点，**仍必须对齐网格、不能重叠**。
- 端点不支持连续滑动，只支持沿建筑边框按网格移动，不得脱离建筑。
- 建筑能否作为来源/目标仍由其自身能力决定；“边框任意位置”不等于无限原料点可以吞入物品。
- 普通接口和隔离接口仍使用自身四向固定端口。
- 已被占用的端点不能重复占用，带的0.8米宽及相邻路径占地都需要检查。
- 如何对现有非整数尺寸建筑生成贴边网格候选点，作为几何实现口径见D05，不通过改变已验收建筑比例回避。

### 6.2 建筑接入能力

| 对象 | 可作为传送带来源 | 可作为传送带目标 | 约束 |
| --- | --- | --- | --- |
| 三种原料供给点 | 对应原料 | 否 | 无限供料仍受带首空间限制 |
| 自动烹饪台 | 已完成的熟肉 | 生肉输入 | 保留三槽容量、独立加工及合法产物规则 |
| 自动组合台 | 汉堡 | 配方材料输入 | 保留加工锁定、材料槽位及成品缓冲；非法物品拒收并回堵 |
| 普通十字接口 | 由接入方向确定 | 由接入方向确定 | 第3节的组合、被动调度及无缓存规则 |
| 隔离接口 | 配对通道的输出端 | 配对通道的输入端 | 两通道独立，不跨通道混流 |
| 缓存台 | 库存物品 | 运入库存 | 容量6件；人工取物/交换使用第5节 |
| 店铺原交付区 | 不接入本期实体带 | 不接入本期实体带 | 实体带仅车间开发；原店铺手工存入/取回和收银流程不自动改变 |
| 车间原交付台 | **移除** | **移除** | 成品链路终点改为缓存台 |
| 手工台、垃圾桶等 | 本期不新增接带能力 | 本期不新增接带能力 | 未提出的新接入功能不扩展 |

### 6.3 占地与接合

1. 检查完整路径占地，而非只检查起点、终点。
2. 传送带不能穿过建筑、已有地面物品、其他传送带或禁止区域。
3. 带的首尾段在建筑占地外靠边交接；不能以接入为由插入建筑内部。
4. 带止于接口边缘，接口中心归接口独占；合法贴边接合不等同带与建筑堆叠。
5. 普通带同格交叉、共用中间段、平行重叠均禁止；需要合并/分流用普通接口，需要独立交叉用隔离接口。
6. 不允许通用架高或从设备下方穿过。
7. 玩家可以步行跨过传送带；接口按建筑碰撞规则处理。
8. 保留地图边界、入口安全预留，不堵住区域切换落点。
9. 不恢复已取消的五格建造距离限制。
10. 无合法路径时可以显示非法预览，但第7节的确认必须拒绝真正的非法占地。

## 7. 布置、路径调整与确认

### 7.1 状态流程

```text
建筑首页
  → 传送带布置
  → 选择A（输出建筑/端点）
  → 选择B（输入建筑/端点）
  → 同一调整阶段：方向、类型、路径、取消
  → 选中“确认摆放”按钮
  → 左键或F确认
  → 校验通过后完整放置，直接进入下一轮选择A（不退出铺带状态）
```

- 选建筑本体，取消旧UI设备列表选取方式。
- 选好A后，选B期间始终显示A边框到当前鼠标/键盘光标的预览；悬停B时贴合其真实边框。未选定B时不能确认铺带。
- 铺带成功后清空当前A/B/编辑快照，直接进入下一条带的选A状态；右键与取消仍可回建筑首页。
- WASD控制选择光标/焦点；鼠标选择建筑和路段。
- 同一建筑不能自连；不能输出/输入、端口占用或会形成环路的目标应禁止确认并给出原因。
- 接口、已放置缓存台都可以作为A/B；接口之间可用传送带连接。
- 预览不实际取料或运输；确认后才成为有效设施。

### 7.2 自动初始路径与非法预览

- A、B选好后，默认生成无遮挡的最短直角路径，尽量减少无必要的转折点。
- 对路径形状的选择偏好沿用填写顺序：直线、L形、多折线；具体同长度路径的并列选择不改变合法性规则。
- **若没有合法路径，仍给出与建筑重叠的传送带预览供玩家调整**，不能直接卡在无预览状态。
- 非法部分需要有可见冲突提示；只要仍有非法占地，“确认摆放”就不能成功。
- 不因用户确认或算法未寻得路径而自动穿过建筑、接口、其他带或地图边界。
- 放置时再次校验全部路径、端口、环路和当前场景状态，防止预览期间发生变化。

### 7.3 拖动与关键点

- 直角转弯处有关键点，可拖动关键点改变转弯位置；构成该角的两段随之调整。
- 其他受影响的关键点随路径约束调整；出现新的转弯时自动添加关键点。
- 拖动非关键点的直线段时，该段位置变化，两侧关键点随之调整。
- 保持直角连接，遵循关键点最少原则；不因全局重新寻路抹去玩家正在指定的路径约束。
- 端点始终贴在建筑边框，只按网格移动。
- 不设固定最大控制点数；确认时仍检查重复占地、非法交叉与环路。
- WASD选路段、F进入/确认路段编辑的具体键位口径见D06，不把这一F当成放置指令。

### 7.4 方向、类型

- 布置预览阶段允许A→B或B→A反向；反向时交换端点角色并重新检查建筑能力、接口组合和环路。
- 这里的“方向反转”与将整条路径旋转90度是不同操作，不旋转已选定的A/B建筑或镜头。
- 本期仅有基础带；保留类型位置，后续类型通过原填写的滚轮/E切换约定扩展，不提前增加高级带。
- 隔离接口作为建筑可在放置时旋转，不能因此串接原本独立的通道。
- 已经放置、运行中的传送带禁止改向，也不开放已铺带的路径重调。

### 7.5 全建筑确认条件

- **所有建筑的放置都设置“确认摆放”按钮。**
- **左键和F只有在“确认摆放”按钮已被选中时，才可以触发布置确认。**
- 左键点场景、选建筑、选路段或拖动路径均不能直接放置。
- 普通建筑投影跟随鼠标时，场景左键将其固定；固定后鼠标移动不改变位置，再次左键点空白地面解除固定。点击固定投影本身或已有建筑不解除。WASD可微调，固定状态和最终确认是两个独立步骤。
- F用于确认选中的建筑、端点或路段时，不允许同时触发布置。
- 鼠标点击按钮与“先选中”的衔接方式、键盘焦点切换见D06；不擅自加入双击要求。
- 右键取消保留；所有确认与取消都阻止输入穿透到普通拾取、放下或交互。

## 9. 修改、拆除与物品损失

| 操作 | 规则 |
| --- | --- |
| 传送带/接口/缓存台管理 | 进入现有建筑管理模式点选；取消旧连接列表删除 |
| 拆除单位 | 传送带按整条A-B连续带理解，与原K02一致；如需逐格拆另行提出 |
| 带上有物品时拆除 | 允许拆除；按队列顺序尝试安全落地 |
| 可落地空间不足 | **继续拆除，删除无法落地的剩余物品**；不再取消整个拆除操作 |
| 损失提示 | 报告实际删除的物品种类与数量；不能只提示一个没有内容的“成功” |
| 物品守恒例外 | 只有这类明确的拆除溢出损失可销毁物品，运输不能借用此规则吞物 |
| 拆接口 | 保留相连的断头带，物品保留在原传送带上；接口本身没有缓存可丢失 |
| 放回接口 | 可吸附断头带；只有满足端口、方向、组合、独立通道与无环路条件的接合才生效 |
| 移动/旋转相连建筑 | 先拆除相关带，再操作建筑；不自动拉伸或穿过障碍重铺 |
| 运行中改向 | 禁止 |
| 已放置带路径重调 | 不允许，需拆除重铺 |
| 类型替换 | 若后续开放，保持原路径并继承承载物品；本期只有一种基础带，不新增无意义的替换玩法 |
| 建造成本 | 本期免费、无限建造；退还成本只记录为未来经济系统需求 |
| 取消预览 | 只撤回未确认内容，不误删已建设施 |

本轮明确取消原A15“落地失败则取消拆除”的预期；新的验收必须允许已说明的损失，并核对提示与实际数量一致。
