## 2. 外观及纸片人方式

**已确认外观基准：**沿用现有无道具三视图的黑发、黑瞳、深灰帽、黑黄制服、围裙、短裤与Q版手绘风。原图是设定参考，不能直接拆成完整动作帧。先补右侧，并统一四向头身比、帽子、衣领、围裙、鞋及身体高度。

表情修订（2026-10-18）：用户明确要求平静表情、脸部端正。基础静态/待机以闭嘴、放松眉眼、正面脸部居中为准，不沿用设定图的张嘴兴奋表情。最新[平静版四向样板](v04-character-calm-sample.md)已生成待审，原图与来源保留。

表情参考进一步明确：用户随后提供面部特写，要求以图为准。最新采用闭嘴浅笑、略压低上眼睑、黑色大瞳孔、自然粗眉及双颊短红线，继续保持脸部端正；覆盖上一轮去红线/直嘴的具体表达。参见[用户面部参考版](v04-character-face-reference-sample.md)，已生成待审。

左、右侧建议独立出图，尤其名牌、帽子徽章、衣服开襟等非对称细节不直接镜像。服装沿用三视图，不采用早期提示中的长裤改动。

**推荐渲染方式：**在现有3D世界中使用面向相机的透明纸片，不制作完整骨骼3D人物。保留垂直正交镜头和世界比例；纸片始终朝向相机，人物“转向”靠切换四向图，不旋转成侧薄片。普通直立平面在垂直俯视下会只剩边缘，因此必须先验证面向相机的平面方向。

脚底固定到角色逻辑位置，所有帧共用足底枢轴；起伏只改变帧内身体形态，不让角色节点跟着晃。身体可视大小先接近现有白模在默认缩放下的屏幕占用，再以实际画面确认，不改碰撞半径0.28米。阴影与人物分离，推荐轻量接地阴影。

这是“俯视世界中的正侧背纸片人”，不是改为斜视镜头，也不是只画帽子顶部的纯俯视角色。纸片与机器遮挡须在样板中实际确认。

## 3. 四向与控制

| 情况 | 推荐规则 |
| --- | --- |
| 向屏幕下移动 | 正面 |
| 向屏幕上移动 | 后面 |
| 向屏幕左/右移动 | 对应左侧/右侧 |
| 斜向移动 | 取屏幕位移较大的轴；两轴近似相同时保留上一次有效方向；初次无历史时取上下方向 |
| 手机摇杆轻微抖动 | 沿用移动死区；方向分界加入约10度滞回，避免边界反复换图，样板后调手感 |
| 停止移动 | 保留最后有效朝向，不自动转正面 |
| 持物、操作机器 | 与当前真实面朝方向一致，不为了播动作擅自改变交互朝向 |
| 相机平移/缩放 | 不影响朝向选择；角色及持物随世界位置投影，缩放时共同缩放 |

角色实际交互仍采用V0.3逻辑朝向及范围；四向图仅量化视觉方向，不把斜向移动和交互强行限制为四向。步行仍4米/秒，奔跑8米/秒；键盘Shift、手机摇杆外圈分别沿原规则触发奔跑。

## 4. 动画清单与组合

“持物”会与“走路/奔跑”同时存在，因此推荐拆成移动状态、手部姿态与附加动作，不让持物动画覆盖腿部移动。首版优先交付完整合成序列帧，物品本身独立挂接；是否使用分层手臂取决于样板效果。

以下帧数/帧率是制作起点，所有动作均需四向；素材帧率与游戏运行帧率独立。

| 动画ID | 用途与触发 | 推荐帧数/播放 | 退出条件 |
| --- | --- | --- | --- |
| idle | 按最新反馈恢复第一版可见呼吸/肩臂起伏，头脸与眼部固定，无眨眼/瞳孔动作，脚底固定 | 8帧，4fps，循环 | 移动、取物、真实加工或思考 |
| walk | 空手步行，脚步和身体小幅摆动 | 8帧，10fps，循环 | 停步、跑步或持物 |
| run | 空手奔跑，明显大步幅与身体前倾 | 8帧，14fps，循环 | 松开奔跑、停步或持物 |
| carry_idle | 持物静止，双手或前臂托举，物品独立显示 | 4帧，4fps，循环 | 走、跑、放下、交换、销毁 |
| carry_walk | 持物步行，手部相对稳定、腿部行走 | 8帧，10fps，循环 | 停步、跑步或失去物品 |
| carry_run | 持物奔跑，保持托举，避免物品离手 | 8帧，14fps，循环 | 松开奔跑、停步或失去物品 |
| operate | 玩家正在执行持续手工加工；面向目标，双臂交替或按压动作 | 8帧，8fps，循环至加工结束 | 松开、离开、移动、目标失效、加工完成 |
| think | 空手闲置一段时间后挠头/托腮，末帧可回idle | 12帧，6fps，播放一次 | 任意有效操作立即打断；播完回idle |

idle按用户修订改为8帧后，上述为每方向64帧、四向合计256帧的工作量估算，**不是已生成数量或积分估算**。先验证1个方向的idle/walk/operate以及1组四向静态，再决定最终帧数；可调整重复帧，但不能以简单加速walk充当run而缺乏跑步动作差异。

思考触发已确认：空手、可正常操控且30秒没有有效操作后触发；持物只保持托举待机，不触发思考。动作时长建议约2秒，播放一次后回idle并重新等待30秒，不连续循环。按住加工、建造、缓存选物、收银、订单浏览或生命周期页面中不触发。用户连续拖镜头或操作UI不算挂机；有效输入重新计时并立即打断思考，材质刷新或普通鼠标经过不算输入。

物品交换/放下/取出首版即时切换姿态，不强制新增拾取、放下独立动作，也不等待动画结束才执行操作。若需要这些表现，应另加动作条目。

## 5. 操作机器的边界与状态优先级

**已确认operate首版仅对应真实持续手工煎肉。**目前并不存在“玩家按住自动机器才能工作”的玩法；自动设备自己运行时，不让附近员工长期播放操作动画。手工组合、取放与收银是即时动作，本批不额外制作短交互动作。

暂停/结算/完成：冻结当前帧，不推进动画与思考计时；恢复后重新判断真实状态，旧按住输入不恢复。

正常运行优先级：真实持续加工 → 移动（按空手/持物及走/跑选择）→ 持物静止 → 思考 → 普通待机。移动导致加工失效时，当帧先更新真实加工状态，再选择移动动画，不用动画锁住玩家。

建造、物流编辑、缓存选择与其他禁止人物移动的模式：停止行走/操作/思考，按实际持物状态显示静止；建造沿用原人物约25%透明表现，物品同步淡化但逻辑仍保留。切区、重开或目标销毁清除旧动作引用。

动画循环不产生物品、增加进度或重复调用交互；库存和生产结果仍由原玩法系统唯一决定。完成加工即结束operate，无需等待一轮帧动画播完。

## 6. 持物与遮挡

- 复用当前5种物品：汉堡胚、生牛肉、熟牛肉、生菜、汉堡；本批可先沿用其白模，只为角色挂接与遮挡做适配，不自动扩成全套物品美术任务。
- 每个方向、每帧可配置手部挂点；建议用归一化坐标保存，缩放/裁切后仍可追踪。同步帧序号，避免人物与物品各自跳帧。
- 正面：物品在躯干前，手/前臂适当盖住物品；后面：物品位于身体前方，可被躯干遮挡，但应保留局部边缘或手持提示；左右侧：物品靠对应前方，不穿过身体。
- 第一阶段用粗略前/后层顺序检验；手部遮挡不理想时再拆前臂覆盖层，图层方案必须先经样板确认。不可用始终盖在人物头上的悬浮物替代手持。
- 提前检查原3D物品与透明纸片的深度关系；如方案不可靠，可将“手持状态”物品改为同源2D显示代理，地面与机器内仍走原逻辑，禁止同时显示两个实体。
- 靠近高设备时允许真实遮挡，推荐仅在人物大部被挡住时显示轮廓或适度遮挡提示；是否采用透视显示待样板确认，不默认穿墙可见。
