## 本轮纠正

1. 颈部裂缝的已确认原因：旧导出将首帧头部覆盖到后续帧，导致头部冻结、身体移动。当前导出移除此处理，恢复各帧完整源姿态。侧面头身联动也随原姿态保留；原始绘画动作的自然度仍需审核。
2. 背面思考旧图像摸后颈。已用Maker生成r2，要求手在身体前方托腮，从背面主要看到侧边弯曲手肘、手掌被遮挡；保留原图、请求与返回，由用户核对是否符合预期。
3. 当前源选择由 `states_v1/active-sources.json` 明确指定背面think r2，旧r1记录不覆盖。
4. 所有历史固定头/肩部蒙版版本只作过程记录，不再作为当前审核页或后续制作标准。
5. 用户进一步指出正面持物奔跑头朝前、身体斜向。查看完整源图后确认这也是原图绘画朝向的问题；正面空手奔跑有同类现象。两组已整体重绘为r2，要求头、肩、胸口、腰与髋部统一朝前，正面视角用抬膝和前后遮挡表达步态，不增加八向状态。新图朝向更一致，腿部交替相位与循环自然度仍待人工审核，不将生成成功记为通过。
6. 已知未通过项：正面run和carry_run的两个半周期仍偏重同一侧腿，完整交替不足。又尝试了各一次r3整组修订；front_run部分膝盖方向有变化，但手臂相位仍不完整，carry_run仍未满足对侧抬膝要求，均未通过步态自检。r3原图/请求/返回保留，未替换审核页中的r2，也不再无限自动重试。当前只确认朝向改善，不能将两组记为完成可接入素材。
