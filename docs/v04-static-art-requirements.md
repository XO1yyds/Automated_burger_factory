## 评审与接入标准

1. 检查真实alpha、完整轮廓、无棋盘格/外发光、无错误文字和多余道具；生肉有脂肪白点，熟肉有烤痕，不仅靠颜色。
2. 实际缩小图可辨认；顶面俯视、旋转正确，三槽与六槽真实位置留白，不把图画出的库存当真实物品。
3. 世界视觉与逻辑分离，不修改产量/速度/经济/存档schema，材质加载复用且失败回退。
4. 游戏窗口验证角色朝向、手持、机器槽、放置/旋转、物流与界面，最多两轮自动视觉修订；Android表现单列未测。
5. 生成结果、来源映射、适配规格、启用路径、Agent验收结论及积分台账分别保存；未知消耗绝不估填。
