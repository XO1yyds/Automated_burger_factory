## 已实现行为

- 原店铺保持原地图位置、18×14 米大小、垂直正交镜头、缩放和拖动方式。
- 左上入口区域内或附近按 F 进入独立 18×14 米自动化车间；车间右下返回区按 F 回店。传送保留手持实体，落点被占满时取消传送。
- 入口内有可拾取地面物品时优先拾取，避免传送标记抢占交互导致物品无法清理。
- 车间具有汉堡胚、生牛肉、生菜三个无限供料口，自动烹饪台、自动组合台和成品输出口。
- 两区域共用原交付区的 **5 个汉堡库存**。输出口是同一库存的访问点，不能额外存 5 个。收银仍需玩家主动选择订单并交付。
- L 打开当前区域的产线界面；也可从 B 建筑首页进入。选择上游和下游后点击建立连接或按 F；点击连接行断开。空格或按钮控制全场连接启停。
- 预设五条示例连接，**默认停机**：生肉→烹饪台，熟肉→组合台，汉堡胚→组合台，生菜→组合台，汉堡→成品输出口。
- 每条连接每 0.5 秒最多转移一件；连接图为逻辑输送，没有实体传送带或运输中的库存。
- 先验证下游容量，再转移所有权；满载、材料不兼容或加工锁定时等待，上游物品保留。物流不借用玩家手持栏。
- 烹饪三槽、3 秒加工，组合2秒、成品缓冲1件，保持 V0.1 规则。物流只取熟肉；玩家手动取生肉仍遵循后进先出。
- 连接同区且材料兼容的供料口、设备和输出口；拒绝自连、重复连接、跨区连接和材料不兼容连接。首版不限制同区连接距离。
- 多个下游竞争同一上游时轮换调度优先次序。连接界面显示累计转移件数及等待原因；地面显示逻辑连接示意。
- 新建的烹饪台、组合台可加入产线。移动保留设备身份；拆除设备会移除相邻连接，内部物品仍使用原有安全落地规则。
- 离开车间后生产继续。配置界面、建筑界面不暂停时间；暂停与结算冻结机器和物流；跨天保留连接与库存；重新开始恢复初始设备和停机示例连接。
- 原有占地、地图边界、入口预留和加工中禁止拆移规则保留，没有新增五格距离限制。

## 人工验收流程

| 编号 | 操作 | 预期 |
| --- | --- | --- |
| L01 | 新开游戏，走到左上入口区域按 F | 进入车间；镜头角度和物体比例不变；区域提示更新 |
| L02 | 手持任一种材料往返两个入口 | 手持材料保留，未复制或消失；返回后可继续操作 |
| L03 | 车间按 L | 显示上下游、5 条示例连接和停机状态；打开界面期间当天倒计时继续 |
| L04 | 点击启动全部连接，关闭界面等待约 6 秒 | 无需手动取放即可产生首个汉堡并进入共用交付区 |
| L05 | 等待交付区达到5/5，再打开 L | 输出连接显示满载等待；组合台保留成品；库存不超过5 |
| L06 | 空手在成品输出口按 F 取出一个，等待一次调度 | 库存先减一，再由上游成品补回；手中汉堡不受物流影响 |
| L07 | 在 L 中停止全部连接 | 不再转移；已在加工的设备完成当前加工后等待 |
| L08 | 点击一条连接断开，再选择相同上下游重新连接 | 仅删除/恢复对应连接，不销毁已有材料；重复连接被拒绝 |
| L09 | 尝试生肉→组合台、汉堡胚→烹饪台或设备→自身 | 明确拒绝，原连接和物品保留 |
| L10 | 车间 B 新建一台设备，L 中连接供料或输出 | 新设备出现在列表，可参与产线；无五格建造限制 |
| L11 | 停机并等待加工完毕，再移动或拆除连接设备 | 移动后连接跟随设备位置；拆除移除相邻连接并安全落地内容物 |
| L12 | 启动产线后回店，等待再进车间 | 后台仍生产；店内交付区与车间输出口库存一致 |
| L13 | ESC 暂停，等待后继续 | 时间、机器进度、物流转移全部冻结，继续后恢复 |
| L14 | 暂停结束当天，进入下一天 | 连接、启停状态、库存和加工进度保留；每日统计重新计算 |
| L15 | 第三天完成后重新开始 | 回到店内第一天；清空动态库存/统计，恢复5条停机连接及初始设备 |
| L16 | 配置界面 ESC、L 或右键关闭；之后操作 F/Q/B | 关闭输入不穿透为拾取/放置；原交互和建筑返回规则保持 |
| L17 | 在入口范围内丢下物品，面向物品按 F | 优先拾取/互换地面物品；清理后可正常传送；落点全被占用时保留当前区域、镜头和手持物 |
