# V0.5 反馈修订与复验

日期：2026-10-19。对应用户反馈：设备管理拆电缆、移除重复机器、精简下单组件。

## 修订内容

### 设备管理

原因：旧管理页只识别建筑和实体传送带，电缆拆线命令仅接在电缆编辑工具中。

- 入口：建造 → 管理 → 进入管理 → 切换电缆。
- 按天花板高度2.4米反算点击位置，避免点击被地面建筑抢走。
- 点击线段后，橙红色标示将拆除的连续直线段，分叉、拐角和建筑锚点为范围边界。
- 点击拆除后仍留在电缆管理，可继续选择下一段；拆线不删除机器内物品。
- “取消选中”先清选中，再返回选型；ESC遵循原有建造返回规则。切回设备或退出后隐藏电缆。
- WASD移动网格光标、F选线；按钮仍可Tab选中后F确认。实际键盘操作由用户复验。
- 电缆编辑页原有删除工具保留，两个入口使用同一网络删除逻辑。

### 机器共用

- 移除初始电缆烹饪台、电缆组合台；不新增专用机型。
- 电缆示例改接车间烹饪台、车间组合台。初始可管理建筑5个，同网端点仍7个。
- 两台机器继续支持原有手动和实体传送带规则。
- 下单任务请求忙碌机器时，暂停该机器新投料，让旧加工与旧成品先经原出口处理，再交接。完成或取消后释放交接/占用状态。
- 旧成品不抵扣“新制作N件”。下游缓存满时，任务提示取走原有成品或疏通下游，不删除旧物品强行交接。

### 下单组件默认显示标准

| 页面 | 默认内容 | 按需展开/进入 | 固定区域 |
| --- | --- | --- | --- |
| 下单首页 | 汉堡、熟牛肉两类可制品，简短说明，行内“选择” | 选择产品进入详情 | 标题、下单/网络/任务页签 |
| 下单详情 | 产品×数量、成品去向与载荷、可生产或缺口提示 | 更换去向；配方与材料详情 | 数量±1/±10与当前值、底部“制作N件” |
| 去向选择 | 同网库存/缓存台名称与载荷、行内选用 | 超过8个分页 | 返回后保留产品及数量 |
| 网络 | 连接数量、带宽、非零存量/无限供料汇总 | 设备、预约、加工、受阻等明细 | 标题、页签、汇总 |
| 任务 | 当前任务产品、进度、阻塞原因、同行取消 | 已结束任务默认折叠，展开最近4项 | 标题、页签、队列数量 |

通用：沿用灰黑色面板、统一字体和48逻辑单位按钮；长内容使用同一滚动区；取消按钮跟随对应任务，避免另列一批无法辨认的取消按钮。隐藏详情不删除数据或真实能力。
