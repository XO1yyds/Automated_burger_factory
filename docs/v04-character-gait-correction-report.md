## 修正标准

- 第1/5帧由相反的腿在前/支撑，第3/7帧由相反的腿经过或抬起。
- 近腿/远腿身份和遮挡连续，不能把同一侧腿的四帧重复两遍；衣物对称不代表可整个人物镜像。
- 空手行走/跑动手臂与对侧腿配合，持物手臂维持身体前方托举。
- 正背朝向一致，背面跑动不在画面中侧倾、横跨。
- 全帧保留完整头身，不切头、不贴头、不冻结头部；眼部不额外处理。
