# Demo V0.1 · 验收后第一轮调整

2026-10-14（Asia/Shanghai）。用户报告原阶段4–8验收功能全部通过，随后提出9项调整。本轮新行为需要补充复测；原验收结论与新修改结果分别记录。

| 问题 | 本轮确定的规则 |
| --- | --- |
| 1 昵称可读性 | 世界 Text3D 白字、加厚暗描边及深色半透明背景；字高约0.28m。文字与背景都是建筑根节点的子节点，靠近同显同隐，移动后依附建筑；不改镜头比例 |
| 2 生肉取回 | 有熟肉时仍优先取最早完成熟肉；没有熟肉时取最后投入的生肉。生肉取回后再放入进度归零；三个槽依旧独立计时 |
| 3 信息栏 | 不按初始两台机器ID固定显示。只显示当前前方有效交互目标那台自动设备的信息；未对准时显示“当前没有自动化设备”，即使场景里有设备也使用此文字 |
| 4 重开行间显示 | 只定位，不修复；没有调整信息栏gap、字号、行高或引擎库。诊断结果见本轮证据与hud-spacing-diagnosis.md |
| 5 建筑距离 | 新建、选择、移动、删除全部取消五格限制；仍保留地图边界、占地/入口/玩家/地面物品冲突及加工限制。普通F前方交互距离仍约1格；远处管理使用鼠标 |
| 6 回退 | 右键逐层；ESC从任何建筑子界面回到建筑主界面，再次ESC才退出建筑模式。退出建筑模式后ESC才暂停 |
| 7 合并建造状态 | B→建筑选择→可定位/旋转/直接确认的预览→放置后保持预览。没有额外准备放置步骤；成功后保留类型、位置及朝向，需移到下一合法位置。已有设备移动确认或删除成功后返回管理，可继续选设备 |
| 8 奔跑 | 左右Shift任一按住时普通场景速度4m/s→8m/s，松开恢复；斜向归一化。建筑/收银/暂停不能因此移动玩家或加速投影 |
| 9 垃圾桶 | 普通场景靠近面向垃圾桶，F直接销毁一件手持物；包括胚、生肉、熟肉、生菜、汉堡。空手无效果，不清地面、库存、设备内容，不改变既有制作统计 |
