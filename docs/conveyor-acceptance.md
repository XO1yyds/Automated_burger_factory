# V0.2 实体传送带统一验收

日期：2026-10-18。范围：策划案R4 A01～A38。**本文件交用户最终验收，尚未标记用户通过。**

建议按以下顺序完成一轮。普通试玩版本不自动执行开发测试；不要把旧“连接式物流”验收结论替代本次结果。开发端证据和环境限制见 [开发交付记录](conveyor-development.md)。

## 准备与操作

1. 打开Windows本地Demo；鼠标点一下游戏场景，使用英文输入状态。
2. 从店铺左上入口按F进入车间。默认有五条实体带，成品进入右侧六槽缓存台。
3. 滚轮缩放、中键拖镜头；保持原垂直正交和场景比例。网格每格1米。
4. 当日时间归零后仍可整理测试；收银台可以结束当天。暂停页面可直接结束当天。

## 第一轮：默认样例、堵塞、缓存台（A01～A04、A14～A18、A34～A38）

1. 进入车间观察原料→烹饪台→组合台→缓存台。应存在五条可见带，物品沿带移动；第一批汉堡约需半分钟，不会点击后立即进入远端设备。
2. 在空闲带段观察同一物品：约2秒移动1格。缓存台达到6件后停止接收，带尾排队、逐渐回堵；不得超过容量、穿过前物或隐性销毁。
3. 离开车间，等一段时间返回：产出继续。店铺交付库存不会因车间产出自动增加。
4. 空手面对缓存台F：只进入选取，角色不随WASD移动；选中汉堡F取出。再次持汉堡进入，选空槽F存回。
5. 从供料点取生菜，进入缓存台选一个汉堡槽F：手中变汉堡，该槽变生菜，总数不变。首次持物F不能直接交换第一格。
6. 空手选空槽F应失败且不改库存；满台不能再向空槽存入。鼠标点槽完成同等操作，右键/ESC取消不取物、不丢弃。
7. 保留一个汉堡在手，返回店铺，手工放进交付区，再到收银台交单：店铺交付/订单仍为原规则。

## 第二轮：建造、路径与确认（A19～A28、A32～A33、A35）

1. B→选择接口或缓存台。把投影移到合法空地：场景左键和未选确认按钮的F均不能建造；选确认按钮后才能放置。成功后仍能连续建造；无五格距离限制。
2. 选择传送带布置，先点建筑A，再移动鼠标或键盘光标：应始终显示A到当前位置的预览。再点B，不出现旧输入/输出设备列表；进入同一调整阶段，有方向、基础类型、路径和取消。
3. 连接两个空地上的缓存台，检查默认最短直角路线；拖直线段、内部角点和端点，观察相邻段随动、自动增加/删除冗余拐点、保持贴边和逐格移动。鼠标和键盘两种方式都做一次。
4. 点击反转方向；只有端点能力允许且不形成环路时才可确认。不能反向向无限原料点送货；已放置的带无原地改向或改路径入口。
5. 故意让预览穿过机器、已有带、地面物、入口或边界：显示红色预览及原因；确认失败。无自动合法路径时仍可编辑红色预览。
6. 分别验证右键：调整→选B→选A→建筑首页；ESC从任意子状态直接回建筑首页，第二次退出。取消按钮在尚未选A/B时也应能退出。
7. 试图自连、跨区或通过两个缓存台连接成有向闭环：必须拒绝。两条普通带不能交叉、叠放或共用中段。
8. 管理已接带的设备：尝试移动/旋转后确认，提示先拆相关带；不自动拉伸原带。传送带可以步行跨过，接口保持建筑碰撞。

## 第三轮：普通接口和隔离接口（A05～A13、A27～A28）

建议在记录默认样例结果后清理车间：先拆五条带，再等正在加工的机器完成后拆机器及缓存台。固定供料点、返回入口保留。按“车间中心”为(0,0)、上方为正Z理解以下布局；为布线留出空格。

| 专项 | 布局与操作 | 预期 |
| --- | --- | --- |
| 空口/单边 | 中心放十字接口，只接输入带或只接输出带 | 可以逐步建造；没有凭空产出；接口不藏库存 |
| 三进一出合并 | 中心十字，底部(0,-4)放缓存台；三种供料点分别绕到上/左/右输入；下口输出到缓存台 | 三类都能到达，轮询不饿死；出口是吞吐短板。先少接一条可测2进1出；只留一条可测1进1出 |
| 一进三出分散 | 中心十字；上口供料；左(-6,0)、右(6,0)、下(0,-4)分别放缓存台 | 各支路轮询分配，满支路跳过；入口为吞吐短板。少一支测1进2出 |
| 普通2进2出 | 四口分配成2输入2输出 | 最后一条非法连接不能确认，清楚提示组合不支持 |
| 直通隔离 | 中心改放直通隔离接口；上下组成一条独立通道，左右另一条，分别送不同材料 | 允许2进2出，两路不串料；堵一路不影响另一路 |
| 转角隔离 | 改放转角接口，按端口颜色配对布线；拆相关带后旋转重放再接 | 配对随旋转变化，两通道仍独立；通道没接全时该通道不运行 |
| 错料回堵 | 从汉堡胚点接自动烹饪台 | 带不筛料，机器拒收；材料停在带尾，不被吞入或销毁 |

缓存台要留足2×4格，旋转后为4×2；不能挡返回入口。上述是分开的专项场景，不要求一张地图同时放下全部布局。

## 第四轮：栈输出、拆除与生命周期（A18、A29～A31、A36～A37）

1. 两个缓存台连单向带。上游依次人工存入“汉堡胚→生菜→生肉”，确认给输出带的顺序为“生肉→生菜→汉堡胚”（后进先出）。带内顺序保持先进先出，不能超车。
2. 上游继续输出时选中一个槽：若被传送带取走，提示重新选择，不能再次F取走旧物；新占槽物不能被旧选择替换。人工选择不冻结整条产线。
3. 管理一条载有不同物品的带，Q拆整条：依队列顺序尝试落地，继续留在管理页面。对照落地数和原队列，不得复制。
4. 空间不足的极端拆除已由开发端受控阻塞检查验证：仍拆除，提示实际损失种类/数量。人工可在拥挤地面复核；不要把“删除取消”作为预期。
5. 拆接口：连接带和带上物品保留为断头带；原位重建兼容接口后吸附恢复。两端接口依次重建也可恢复；不兼容通道、2进2出或环路不应强行接合。
6. 运输中ESC暂停，观察至少5秒：货物、机器、时钟停止；恢复后继续。暂停→结束当天→结算同样冻结；下一天货物、缓存和连接保留。
7. 完成第三天后重新开始：恢复五条初始实体带、两台车间机器和六槽缓存台；没有旧库存/旧选择/旧施工预览；原店铺布局及单件手持规则保持。

## 本轮问题重点复验（R4）

- [ ] 第二轮2/3：W/A/S/D分别选择画面上/左/下/右的节点或路段；没有该方向目标时不绕到另一头。
- [ ] U形折返：拖动一端转弯节点，相关直线一起移动；拖到对齐位置合并成更短的L形，不出现360度转弯/重叠队列。
- [ ] 同一次F编辑中，左右/上下反向走回原坐标，路径回到原形；重复往返不累积额外转折。
- [ ] a：移动建筑投影→场景左键固定→移动鼠标投影不动；点投影或已有建筑保持固定；点空白解除，随后重新跟随。固定不等于建造。
- [ ] b：已选A、未选B时，预览始终跟随当前位置；移到B贴边，空白处点选不能当正式B或直接铺带。
- [ ] c：确认铺带后直接进入新一轮选A，不返回建筑首页、不保留旧A/B；右键仍能退回首页。
