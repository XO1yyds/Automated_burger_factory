| 订单 | 自动生成/接受，间隔随机5～15秒，首单也等待；最多5个未完成订单，满单暂停，腾位后重新等待随机间隔；HUD 显示编号、交付/需求数量 |

## 建筑操作

| 状态 | 键盘 | 鼠标 |
| --- | --- | --- |
| 进入选型 | B；A/D 切换，F 选型 | 移动到选型按钮即选中类型，左键选型 |
| 选型预览 | F 进入准备放置 | 左键进入准备放置 |
| 准备放置 | WASD 一格微调；R 旋转；F 确认 | 移动鼠标定位；每格滚轮旋转90°；左键确认 |
| 连续建造 | 成功后回到当前类型预览；ESC 退出 | 成功后继续预览；右键退出 |
| 管理已有建筑 | B 后 Tab；F 选前方建筑 | 点“管理已有建筑”，左键选择场景建筑 |
| 移动已有建筑 | WASD/R 调整，F 确认，Q 删除 | 鼠标/滚轮调整，左键确认 |
| 取消 | ESC 返回普通操作，移动取消保留原建筑 | 右键取消 |

建筑页面、放置和收银界面锁定玩家移动，自动设备与订单仍更新。建筑状态的 Q 只用于删除选中建筑，不会丢弃手持物。准备放置/移动时滚轮用于旋转，普通操作时滚轮缩放相机，中键平移保留。

收银操作：W/S 或 A/D 选订单，F 交付；也可点击订单行再点“交付”。ESC/右键关闭。打开收银台不自动选择订单，完成后不自动向下一单交付。

## 一次人工验收流程

1. 检查场景比例与此前恢复后的版本一致。靠近、离开建筑，再拖动/缩放镜头，观察世界昵称始终依附该建筑。地面物品仍使用上侧居中对准名称。
2. 验证手工煎肉仍需放料后重新连续长按F三秒，中断归零；手工组合立即生成汉堡。
3. 对自动烹饪台分时投入三块生肉，观察三槽独立剩余时间；尝试满槽投入和提前取出再放回；熟肉占槽且取出优先。
4. 对自动组合台投入胚、生肉、菜，确认不生成汉堡；空手先取出生肉，更换熟肉，确认两秒加工。加工中尝试取回/投入，成品未取时缓存新配方并确认不会继续加工。
5. 按B，分别用键盘和鼠标建造两种设备。检查预览与准备放置分开，旋转改变占地，非法红色投影不能确认；超五格、越界、占玩家/地面物品/入口/固定设施时均拒绝。
6. B→Tab 或点管理，选择已有设备。移动后取消，检查原位、原朝向和内部物品；再移动确认。加工中尝试移动/删除，应拒绝。
7. 非加工设备留有材料或成品时删除，检查全部物品落到合法地面，手持物保留。若空间不足，不删除、不丢内容。
8. 等待订单出现，观察最多五单。将制作的汉堡存入交付区，尝试容量限制与取回，确认无法放入生肉等非汉堡物品。
9. 收银台F打开，未选单时交付按钮禁用；分别用键盘、鼠标选择并交付，确认库存扣除、完成订单移除、选择清空与下一次随机等待。
10. 部分交付已由真实收银按钮回调和三份需求测试订单验证；当前Day 1每单一份，人工跨日部分交付需后续Phase 8。查看下述证据中的部分交付与剩余库存条目。
