## 预览工具的限制与日志问题

- 初版会话曾输出 `[Phase1] READY`。CLI `preview check` 返回 FAIL、`ready=false`，原因是 Runtime 日志包含错误；不能把这个结果记作“预览检查通过”。本轮开始时会话已停止，用户明确同意“重新打开并自检”后才重新启动。
- 当前 Runtime 报告 `Could not find resource Cube/Day/DaySpecularHDR.dds` 和 `Can not load themis_x64.dll`。日志显示脚本仍已加载且物理自检执行完成，但这些问题对最终画面的影响未经视觉核实。
- 新版普通操作会话已加载 `orthographic=top-down90, layout=reference2`，本轮 `preview check` 仍因上述 Runtime 日志错误返回 FAIL；十项机制自检通过与工具 FAIL 分别记录，不混为整体通过。
- CLI 没有截图或输入自动化能力，本轮画面可读性和真实键鼠手感为 UNDETERMINED，需用户在已打开的窗口验收。
- 非提升权限的状态查询一度无法确认宿主身份；随后使用相同 CLI 的授权查询确认同一会话仍存活，没有重复启动或按 PID 强制终止。
- 新项目本地配置只由 CLI 在受管理预览副本补齐；未伪造原项目 `.project` 配置，未进行远程构建、提交或推送。

## 用户验收步骤

1. 检查房间、玩家、七个工作点、左上入口和垃圾桶名称能看清，HUD 不遮住关键操作区域。
2. 按 W/A/S/D，确认对应屏幕上/左/下/右；同时按两键，确认对角线不会明显更快。
3. 持续朝每个工作台及四面墙移动，确认无法穿过；沿边缘移动应能正常绕行。
4. 靠近并面向工作台，确认黄色高亮和 F 提示；按 F 查看目标名称反馈。
5. 背对工作台或移出约 1 格范围，确认提示消失；远处按 F 不应检测到目标。
6. 确认镜头垂直向下；滚轮能缩放、中键拖动能平移、鼠标不能旋转；改变窗口尺寸后地图与标签仍可读。
7. 对照图 2 确认左上入口、顶部组合台/铁板/三原料点、左侧垃圾桶、下方收银台及其右侧交付区的位置。
