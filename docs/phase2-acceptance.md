# Phase 2 · 物品验收

日期：2026-10-14。状态：标签与互换修复已实现，29 项物品自检、10 项 Phase 1 回归和 2 项实际 UI 布局检查通过，等待用户验收。Phase 3 手工生产尚未开始。

## 范围

- 五种独立类型：汉堡胚（bun）、生牛肉饼（raw_beef）、熟牛肉饼（cooked_beef）、生菜片（lettuce）、汉堡（burger）。颜色和名称区分，生肉与熟肉不混用。
- 没有背包，手上最多一件。手持实体随玩家面向更新，HUD 显示类型及 ×1。
- 图 2 右上三个固定原料点无限取料：空手 F 获取一份；持物 F 换取该原料。用户已确认旧物去向：旧手持物放在附近有效地面，新原料进入手中；附近没有空位则完全不交换。原料点类型始终固定，库存仍无限。
- 地面物品按前方、约一格、最近目标选择；遮挡物后的物品不可隔墙交互。空手 F 拾取并移除地面实体；持物 F 与地面物品互换，新物品进入手中，旧手持物占据该地面物品原位置，地面数量不变。
- 地面物品和原料不再使用跟随世界坐标的悬浮名称；对准有效目标后，屏幕上侧正中显示其名称，无目标时隐藏。建筑/区域名称保留地图提示。
- Q 将手中物品放到附近有效地面。优先前方，空间受阻时寻找附近替代位置；不穿入建筑/垃圾桶、不越界、不叠在其他物品上。没有有效位置时原物品留在手中；空手 Q 无效果。
- 同一帧 Q 优先于 F，避免同时按键造成丢下又立刻拾回。
- 维持图 1 纯俯视镜头与图 2 布局；不扩展生产、建造、收银、订单或垃圾桶功能。

## 临时验收样品

为了在生产链尚未实现时验证全部五种物品，本阶段在中央空地放置五份样品：X 为 -3.2、-1.6、0、1.6、3.2，Z 为 1.8。它们可以正常拾取和丢下，不是新原料点。

熟牛肉饼和汉堡本阶段只由这组样品提供，不允许从三个原料点直接获取。进入 Phase 3 时移除这组样品，改由真实手工生产链生成熟肉和汉堡。

## 人工验收

1. 检查五份地面样品的颜色；对准后名称出现在屏幕上侧正中，与 F 提示指向同一目标。移动、缩放、平移镜头时名称不跟物品偏移；无目标时隐藏。
2. 空手到右上三个原料点，面向按 F：每次只得到对应原料一份，HUD 显示手持 ×1。
3. 持物时对另一地面物品按 F：两种物品互换，旧手持物留在对方原位置；反复交换不会增加物品数量，手上始终一件。
4. 持物时对原料点按 F：取得对应原料，旧手持物留在附近合法地面；没有空位时，手中物品和地面数量不变。
5. 把物品放下，再去同一原料点重复取料，确认没有库存、金钱或次数限制。
6. 在墙边、工作台边和已有地面物品旁按 Q，确认物品落在附近合法位置；无法找到空地时不丢失物品。
7. 空手 Q 无效果；背对或超距的地面物品不能交互。
8. 将多个物品丢在附近，确认 F 选择最近的前方目标；空手拾走后不残留实体，互换时保留原位置的单个实体。
9. 验证玩家碰撞、固定俯视方向、滚轮缩放和中键平移仍正常。
